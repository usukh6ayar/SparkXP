# BE хүсэлт (Choi → Өсөхбаяр): streak freeze хэд удаа зарцуулагдсаныг API-аар өгөх

**Огноо:** 2026-08-04 · **Хэмжээ:** ~2 мөр + 1 багана
**Файл:** `backend/src/xp/gamification.ts` · `backend/src/xp/xp.service.ts`

## Асуудал

`isStreakAlive()` (2026-08-03-нд нэмэгдсэн) нь өдөр алгассан үед **мөстөлтийг
чимээгүйхэн зарцуулдаг** — тэр нь зөв. Гэвч `GET /gamification` нь үүнийг
**хаана ч мэдээлдэггүй**: хариунд зөвхөн `streakFreezes` (үлдсэн тоо) байна.

Үүнээс болж сурагчийн талаас мөстөлт нь **ажилласан эсэх нь харагдахгүй**:

- Тэр 100 Sparks төлсөн.
- Маргааш нь streak нь тасраагүй байна.
- Гэхдээ *яагаад* тасраагүйг нь апп хэлж чадахгүй — «би зүгээр л азтай байсан
  юм болов уу?» гэж бодох эрсдэлтэй.

Мөстөлтийн үнэ цэнэ нь **түүнийг ашигласан мөчид харагдах** ёстой, эс бөгөөс
дахин худалдаж авах шалтгаан алга.

## Хүсэлт

`getGamification()`-ийн хариунд **нэг талбар** нэмэх:

```ts
return {
  ...
  streakFreezes: user?.streakFreezes ?? 0,
  streakFreezesUsed: <энэ streak хэдэн алгассан өдрийг мөстөлтөөр даван туулсан>,
  ...
};
```

**Утга:** одоогийн (тасраагүй) streak-ийн хугацаанд зарцуулагдсан мөстөлтийн
тоо. Streak тасрах үед **0 болж дахин эхэлнэ** (шинэ streak → шинэ тоолуур).

### Хадгалах хамгийн хямд арга

`users` хүснэгтэд `streak_freezes_used_current INT NOT NULL DEFAULT 0` багана
нэмээд:

- `isStreakAlive()` мөстөлт зарцуулах болгондоо `+1`;
- streak тэг болж шинээр эхлэх мөчид `0` болгох (`currentStreak = 1` тавьдаг
  газартаа хамт).

Redis-д тавьж болохгүй: энэ нь «үзсэн» туг биш, **сурагчийн худалдаж авсан
зүйлийн түүх** тул алдагдвал мөнгө нь алга болсон мэт харагдана.

## Mobile тал юу хийсэн бэ (одоо блоклогдоогүй)

`Gamification`-д **optional** `streakFreezesUsed?: number` гэж тодорхойлсон
(`mobile/src/api/gamification.ts`). Ирээгүй үед UI нь тэр мөрийг **огт
харуулахгүй** — таамагласан тоо хэзээ ч гарахгүй.

Ирмэгц дараах 2 газар автоматаар асна:

1. **Streak баяр хүргэх цонх** (`useCelebrations.ts` → `freezeNote()`) —
   «Энэ дарааллыг 2 хоног мөстөлт хамгаалсан» гэсэн чип.
   Тоо ирээгүй/0 бол оронд нь «2 хоногийн мөстөлтийн хамгаалалттай» (үлдэгдэл).
2. **Streak мөстөх sheet** (`StreakFreezeSheet.tsx`) — мөстөлт худалдаж авах
   цонхны дунд нэмэлт мөр.

## Шалгах

`GET /gamification` хариунд `streakFreezesUsed` гарч ирвэл mobile талд
өөрчлөлт хийх шаардлагагүй — optional тул автоматаар хэрэглэгдэнэ.
