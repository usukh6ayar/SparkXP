# BE хүсэлт (Choi → Өсөхбаяр): флашкартын XP + streak-ийн дүрэм

**Огноо:** 2026-07-29 · **Файлууд:** `backend/src/reviews/reviews.service.ts` ·
`backend/src/xp/xp.service.ts`

Хоёул нэг л шалтгаанаас гардаг: **давталт (flashcard) XP олгодоггүй.**

---

## 1. `POST /reviews/:wordId` XP огт олгодоггүй

`ReviewsService.submit()` нь SM-2 хуваарийг шинэчилж `WordReview` буцаадаг —
`XpService` рүү нэг ч дуудлага байхгүй. Гэтэл `XpSource.WORD_REVIEW` enum нь
**аль хэдийн байдаг** (`common/enums/index.ts:115`), өөрөөр хэлбэл анхнаасаа
төлөвлөсөн боловч хэрэгжээгүй байна.

**Үр дагавар (хэрэглэгч мэдээлсэн):** сурагч флашкарт үзээд «+300 XP» гэж
хараад, XP нь огт нэмэгддэггүй.

**Mobile талд юу хийсэн:** тэр «+300 XP» нь **mobile талын зохиомол тоо**
байсан (`swipe.tsx` `+10` / `+2` гэж дотооддоо тоолж байсан) — устгасан.
Одоо үр дүнгийн дэлгэц зөвхөн бодит тоо харуулна (нарийвчлал / мэдсэн /
давтах / үзсэн карт).

**Хүсэлт:** `submit()` дотор XP олгох:

```ts
// quality >= PASS_THRESHOLD үед л, эсвэл бага хэмжээгээр бүх давталтад
await this.xp.award({
  userId,
  amount: passed ? 10 : 2,        // тоог та шийднэ үү
  source: XpSource.WORD_REVIEW,
  referenceId: wordId,
});
```

⚠️ **Anti-abuse:** нэг үгийг дахин дахин шудрахад XP тармах боломжтой.
`awardOnce`-ыг (user, WORD_REVIEW, wordId)-оор ашиглах эсвэл өдөрт нэг удаа
гэж хязгаарлах нь зүйтэй болов уу. Энэ талаар та шийдвэрлээрэй.

**Хариунд `xpEarned` нэмэх** — mobile тал бодит тоог харуулна
(`/quizzes/:id/submit` яг ингэдэг). Тэр талбар гармагц XP хавтанг буцааж
тавина.

---

## 2. Streak нь өдрийн зорилтоос хамаардаггүй

**Одоогийн зан төлөв** (`xp.service.ts`, `award()` доторх): streak нь тухайн
өдрийн **анхны XP** дээр ахидаг —

```ts
if (user.lastActiveDate !== today) { ...resolveStreak... }
```

Өөрөөр хэлбэл **1 XP олоход streak нэмэгдэнэ**. Өдрийн зорилт (20/50/100 XP)
streak-т огт нөлөөлдөггүй.

**Хэрэглэгчийн ажиглалт зөв:** «зорилгоо биелүүлэхээс өмнө streak нэмэгдэх шиг
болсон» — яг тийм. Мөн флашкарт XP өгдөггүй тул (§1) флашкарт үзэхэд streak
**огт хөдөлдөггүй**, энэ нь бүр төөрөгдүүлж байна.

**Хүсэлт:** streak-ийг **өдрийн зорилт биелэхэд** ахиулах:

```ts
// award() дотор, XP нэмсний ДАРАА
const todayXp = /* тухайн өдрийн нийлбэр */;
const goal = user.dailyGoalXp ?? DAILY_GOAL;
if (user.lastActiveDate !== today && todayXp >= goal) {
  ...resolveStreak...
}
```

Duolingo яг ингэдэг — streak нь «орж үзсэн» биш «зорилтоо биелүүлсэн» гэсэн
утгатай байх нь streak-ийг утга учиртай болгоно. Одоогийн байдлаар нэг асуултад
хариулаад гарахад streak ахидаг тул хэмжүүр сул.

⚠️ Анхаарах: `resolveStreak()`-ийн freeze логик хэвээр ажиллах ёстой. Мөн
өдрийн зорилтоо дунд нь өөрчилвөл (`PATCH /gamification/goal`) юу болохыг
бодох хэрэгтэй — жишээ нь зорилтоо 100-аас 20 болгож бууруулаад streak авах.

---

## Хэрэв §2-ыг өөрчлөхгүй бол

Тэгвэл mobile талд **тайлбар нэмэх** хэрэгтэй — одоо сурагч «зорилт биелүүлбэл
streak нэмэгдэнэ» гэж ойлгож байна. Аль нь болохыг хэлээрэй, би тохируулна.
