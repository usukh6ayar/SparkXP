# BE хүсэлт (Choi → Өсөхбаяр): өдрийн дасгалын тоолуур + дуусгасны шагнал

**Огноо:** 2026-07-30 · **Файлууд:** `backend/src/gamification/*` ·
`backend/src/sparks/*`

Soril дэлгэцийн "Амжилтын зам" (Path to success) нь **юу ч хэмждэггүй** байсан —
`gam.progress × 5`, өөрөөр хэлбэл тухайн level дотор XP-ээрээ хэдэн хувьтай явааг
5 цэг болгон харуулдаг байв. Сурагч нэг дасгал хийхэд цэг нь бараг хөдөлдөггүй
тул зогссон мэт харагддаг байсан.

**Mobile талд юу хийсэн (2026-07-30).** Зам нь одоо **өнөөдөр дуусгасан дасгалын
тоо**-г харуулна (`DAILY_TASK_GOAL = 5`). Тоолуур нь одоогоор **төхөөрөмж дээр**
(`mobile/src/lib/dailyTasks.ts`) — өдөр солигдоход өөрөө 0 болно.
`app/quiz/[id].tsx` дээр `res.passed` үед `markDailyTask()` дуудна.

---

## 1. Өдрийн дасгалын тоолуур — сервер тал дээр

**Асуудал.** Локал тоолуур нь (а) өөр төхөөрөмж дээр 0-ээс эхэлнэ, (б) апп
устгавал алга болно, (в) хамгийн гол нь **шагнал олгоход итгэж болохгүй** —
хэрэглэгч AsyncStorage-ийг өөрчилж чадна.

**Хүсэлт.** `GET /gamification` хариунд 2 талбар нэмэх:

```ts
/** Өнөөдөр (сурагчийн цагийн бүсээр) дуусгасан standalone дасгалын тоо. */
todayExercises: number;
/** Өдөрт хэдэн дасгал хийвэл дүүрэх (admin/DB-ээс тохируулна). */
dailyExerciseGoal: number;
```

`quiz_attempts`-аас `passed = true AND created_at >= <өнөөдрийн 00:00>` гэж
тоолоход хангалттай байх. Босгыг **DB/admin-аас** авбал апп шинэчлэлгүй
тааруулах боломжтой (CLAUDE.md-ийн дүрэм).

## 2. Зам дүүргэсний шагнал

Сурагчийн асуулт шууд: *"өдөрт дасгал бүрээд нэгийг хийж байж энэ дүүрч XP эсвэл
spark авдаг юм уу?"* — одоогоор **авдаггүй**. Зам зүгээр л дүүрээд зогсоно.

**Хүсэлт.** Өдрийн зам дүүрэхэд нэг удаа Sparks олгох:

```
POST /gamification/daily-path/claim   → { sparksAwarded, alreadyClaimed }
```

⚠️ **Anti-abuse:** өдөрт нэг удаа (`SparksLog`-д `(user, DAILY_PATH, <өдөр>)`
түлхүүрээр `awardOnce`), мөн дасгал үнэхээр дууссан эсэхийг **сервер тал дээр**
шалгах — client-ийн тоог битгий итгээрэй. Хэмжээг та шийднэ үү (10–25 Sparks?).

Энэ хоёр ирэх хүртэл mobile тал нь локал тоолуураар ажиллана, **шагнал огт
олгохгүй** — байхгүй шагналыг байгаа мэт харуулахгүй (`swipe.tsx`-ийн хуурамч
"+300 XP"-ийн алдааг давтахгүй).
