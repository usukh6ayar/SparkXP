# Имэйл (OTP + нууц үг сэргээх) — ажиллаж байгаа тохиргоо

> Төлөв: **Brevo HTTPS API** дээр ажиллаж байна (2026-08-06-нд батлагдсан,
> Inbox-д хүрсэн, spam биш).

---

## Яагаад Brevo вэ — өмнөх хоёр нь яагаад бүтээгүй вэ

| Провайдер | Үр дүн |
| --- | --- |
| **Gmail SMTP** | Локал дээр ✅ · Railway дээр ❌ **өлгөгддөг** |
| **Resend** | HTTPS тул Railway дээр ажиллана, гэхдээ **домэйнгүй бол зөвхөн эзэмшигчийн хаяг руу** илгээдэг |
| **Brevo** | ✅ HTTPS + домэйн шаарддаггүй + өдөрт 300 үнэгүй |

**Хамгийн чухал:** **Railway нь Hobby багц дээр гадагш чиглэсэн SMTP портыг
(25/465/587) бүрэн хаадаг** — зөвхөн Pro-оос дээш нээлттэй. Тиймээс nodemailer
холбогдож чадалгүй timeout хүртэл өлгөгдөж, HTTP хүсэлт нь хамт өлгөгддөг.
Ямар ч env утгаар засагдахгүй. Энэ шалтгааныг олоход хугацаа орсон тул
**дахин SMTP руу буцахгүй байхыг зөвлөе.**

## Одоогийн тохиргоо

```bash
BREVO_API_KEY=xkeysib-…
MAIL_FROM=SparkXP <gantulga.hustlehive@gmail.com>

# Эдгээр ХООСОН байх ёстой (Railway дээр ажиллахгүй):
RESEND_API_KEY=
SMTP_HOST=
```

Провайдерын эрэмбэ (`src/mail/mail.service.ts`): **Brevo → Resend → SMTP → stub**.
Тиймээс `RESEND_API_KEY` тавигдвал Brevo-г **дарна**.

## ⚠️ Мартаж болохгүй 3 зүйл

### 1. IP хаалт унтраалттай байх ёстой

Brevo анхдагчаар шинэ IP-г хаадаг. Эхлээд `401 unrecognised IP address` гэж
өгсөн. Шийдэл:

```
app.brevo.com → дансны dropdown → Settings → Security → Authorized IPs
→ "Deactivate for API keys"
```

**Зөвхөн нэг IP нэмж болохгүй** — Railway-гийн сервер өөр, бас динамик IP-тэй
тул локал дээр ажиллаад prod дээр 401 өгнө.

> Brevo нь 30 хоногийн "суралцах үе"-тэй бөгөөд шинэ IP олдохгүй бол хаалтыг
> **автоматаар дахин асаадаг**. Гэнэт имэйл зогсвол эхлээд энэ хуудсыг шалга.

### 2. "Unsubscribe" дарсан хэрэглэгч OTP авахаа болино

Brevo нь transactional имэйл дээр ч unsubscribe холбоос нэмдэг. Сурагч сониуч
зангаараа дарвал **тухайн илгээгчээс ирэх бүх имэйлээс хаагдана** — өөрөөр
хэлбэл дараа нь нууц үгээ сэргээж чадахгүй болно.

Гараар нээх:
```
Settings → Transactional emails → Blocked or Unsubscribed contacts
→ хэрэглэгчийг олоод unblock
```

Support руу "код ирэхгүй байна" гэсэн гомдол ирвэл **хамгийн түрүүнд энэ
жагсаалтыг шалга.**

### 3. Илгээгчийн хаяг өөрчлөгдөж харагдана

Хэрэглэгч дараах байдлаар харна:
```
SparkXP <gantulga.hustlehive@11835670.brevosend.com>
```

`@gmail.com` биш. Brevo нь өөрийн эзэмшдэггүй домэйнд DKIM гарын үсэг зурж
чаддаггүй тул хаягийг өөрийн дэд домэйнээр сольдог. **Хүргэлтэд сайн** (Brevo-гийн
нэрийн өмнөөс баталгаажсан), гэхдээ мэргэжлийн бус харагдана.

## Домэйн авбал юу сайжрах вэ (~$12/жил)

Заавал биш — одоогийн тохиргоо ажиллаж байна. Гэхдээ домэйн нь:

- Илгээгч `noreply@sparkxp.app` болно (`@…brevosend.com` биш)
- SPF/DKIM/DMARC → spam-д орох магадлал бүр буурна
- Privacy Policy URL `vercel.app`-аас өөрийн домэйн болно
- `support@sparkxp.app` албан ёсны хаяг

Тохируулах: Brevo → Senders, Domains → Add domain → DNS-д 3 бичлэг.
`MAIL_FROM`-оо шинэ хаягаар солино, өөр код өөрчлөх шаардлагагүй.

## Шалгах

```bash
cd backend
npm run test:email -- you@example.com
```

Аппын ашигладаг яг тэр `MailService`-ээр бодит имэйл илгээнэ. Алдаа гарвал
Brevo-гийн хариуны **биеийг** хэвлэнэ (баталгаажаагүй sender / буруу түлхүүр /
IP хаалт / квот) — статус ганцаараа юу ч хэлдэггүй.

**Spam табыг заавал шалга.** Spam-д орсон код бол алдагдсан хэрэглэгч.

## Хамгаалалтууд

- **Production дээр провайдергүй бол сервер асахгүй** (`MailService.onModuleInit`).
  Өмнө нь чимээгүй stub горимд орж OTP кодыг **лог руу** бичдэг байсан — deploy
  эрүүл харагдаж атал бүртгэл бүр бүтэлгүйтэж, логт хандах эрхтэй хэн ч дурын
  дансыг баталгаажуулж чадах байв.
- **Имэйл унавал бүртгэл буцаагдана.** Өмнө нь хэрэглэгч үүсчихээд имэйл унахад
  500 буцаж, дахин оролдвол 409 "аль хэдийн бүртгэлтэй" гээд **бүрмөсөн гацдаг**
  байсан (OTP дэлгэц рүү ороогүй тул "дахин илгээх" рүү хүрэх ч аргагүй).
