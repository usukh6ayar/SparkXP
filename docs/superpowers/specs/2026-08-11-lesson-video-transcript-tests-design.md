# Видеоноос хичээлийн тест үүсгэх (дизайн)

**Огноо:** 2026-08-11 · **Салбар:** `usukhbayar` · **Хамрах хүрээ:** `/backend` + `/admin`

## Асуудал

Админы хичээл засах цонхонд «AI-аар үүсгэх» товч аль хэдийн байдаг
(`admin/src/pages/lessons/LessonTests.tsx`) — `AiBulkGenerator` →
`POST /quizzes/ai-generate` → Gemini → ноорог тест. Гэвч AI-д очиж байгаа
цорын ганц хичээлийн мэдээлэл нь `contextNote: 'Хичээлийн нэр: "..."'`, өөрөөр
хэлбэл **гарчиг**. Видео, тайлбар, хавсаргасан үгс prompt-д огт ордоггүй.

Үр дүн: гарч ирсэн тест хичээлийн бодит агуулгатай холбоогүй, ерөнхий байдаг.
Багш видеон дээрээ юу зааснаас үл хамааран ижил төстэй асуулт гарна.

**Тиймээс энэ бол шинэ онцлог биш** — байгаа генератор руу **хичээлийн бодит
агуулгыг урсгах** ажил.

## Хязгаарлалт (шалгасан, таамаг биш)

| Зүйл | Байдал |
| --- | --- |
| Хичээлийн бичвэр (скрипт/subtitle) | **Байхгүй.** Багш зөвхөн видео upload хийдэг. |
| Видеон дээрх хэл | **Холимог** — монголоор тайлбарлаад англи жишээ. |
| NotebookLM | **Нээлттэй API байхгүй.** Автоматжуулах боломжгүй. |
| ElevenLabs Scribe | Видео файлыг **шууд** хүлээж авна (MP4/MOV/WebM…), 3GB / 10 цаг хүртэл. ffmpeg хэрэггүй. |
| Scribe `source_url` | Байдаг → файлын биетийг илгээхгүй, R2 дээрх URL-ийг өгнө. **Видео Railway-гийн санах ойгоор дамжихгүй.** |
| Манай video upload cap | 200MB (`backend/src/upload/upload.controller.ts`) → бодитоор 30 минутаас урт видео гарахгүй. |
| `gemini-text.ts` | **Зөвхөн текст** (`parts: [{ text }]`). Видео өгөх бол шинэ Files API зам бичих хэрэгтэй. |
| `AiUsageType` | `STT` аль хэдийн байна — шинэ enum утга хэрэггүй. |
| `LessonsService.findAll()` | `content` jsonb-г **бүтнээр** буцаадаг → транскриптийг тэнд хийвэл аппын жагсаалтын хариу хавагдана. |

## Хувилбарууд ба шийдвэр

**A. Транскрипт эхлээд (СОНГОСОН).** Видеог хөрвүүлж, хадгалж, засах боломжтой
болгоод, дараа нь тестийн генератор руу дамжуулна.

**B. Upload дээр бүх зүйл автоматаар.** Транскриптийг засах цэг байхгүй —
"тест муу байна" гэдгээс цааш алдаа хайх боломжгүй. Тест хэрэггүй үед ч мөнгө
зарцуулна. Ангилал/төрөл/тооны сонголт алдагдана. **Татгалзсан.**

**C. Gemini-д видеог шууд өгөх.** Алхам цөөн ч `gemini-text.ts`-д шинэ Files
API зам нэмнэ, дахин ашиглах артефакт үлдэхгүй, токен нь Scribe-аас үнэтэй.
**Татгалзсан** (видео нь бараг яриагүй, слайд төрлийн болвол дахин авч үзнэ).

**A-г сонгосон шалтгаан:** транскрипт бол **хадгалагдах, засагдах артефакт**,
түр зуурын алхам биш —

- нэг хичээлийн 4 ангилалд тест үүсгэхэд дахин хөрвүүлэхгүй (нэг л удаа төлнө);
- STT-ийн алдааг тестэд шингэхээс нь **өмнө** засах цэг үлдэнэ;
- дараа нь субтитр / унших материал / үг гаргахад дахин ашиглагдана.

## Урсгал

```
Админ → хичээл засах → видео upload (одоо байгаа)
     → «Видеоноос бичвэр гаргах»
         POST /lessons/:id/transcribe
         → Scribe (source_url = videoUrl, language_code ӨГӨХГҮЙ)
         → lesson.content.transcript = { text, seconds, at }
     → бичвэр textarea-д гарна, админ ЗАСЧ болно → PATCH /lessons/:id
     → «AI-аар үүсгэх» (одоо байгаа товч)
         → бичвэр prompt-д `lessonSource` болж орно
         → Gemini → ноорог → админ шалгаад хадгална
```

### Транскриптийн чанарын шалгуур

Транскрипт нь **сурагчид харагдахгүй** — зөвхөн AI-д "энэ хичээл юу зааж
байна" гэдгийг ойлгуулах контекст. Тиймээс шалгуур субтитрийнхээс хамаагүй
бага: монгол тайлбар нь бүдэг гарсан ч дунд нь орсон англи жишээ, дүрмийн сэдэв
нь Gemini-д хангалттай. Холимог хэл тул `language_code` **тогтмол өгөхгүй**,
автомат таниулна.

## Backend

### 1. `SttAdapter` — шинэ метод

```ts
transcribeUrl(url: string): Promise<SttResult>
```

`ElevenLabsSttAdapter` дээр `source_url` талбараар хэрэгжинэ. Одоо байгаа
`transcribe(audio: Buffer, mime)` **хөндөгдөхгүй** — buddy voice түүн дээр явдаг.
Одоогийн retry загварыг (5xx дээр нэг удаа) дагана.

### 2. `POST /lessons/:id/transcribe`

- Хамгаалалт: `@Roles(ADMIN, SUPER_ADMIN, MODERATOR)`.
- `content.videoUrl` байхгүй бол `400` — «Эхлээд видео оруулна уу».
- Амжилттай бол `content`-ыг **merge** хийж хадгална (дарж бичихгүй —
  `videoUrl`/`imageUrl` устах ёсгүй):
  `content.transcript = { text, seconds, at }`.
- **Синхрон.** Scribe бодит хугацааны ~1/10-аар боловсруулдаг тул 10 мин видео
  ≈ 30–60 сек. 200MB cap-тай тул бодитоор 30 минутаас урт видео гарахгүй.
  Цаашид урт видео гарвал ElevenLabs-ийн `webhook` горим руу шилжинэ.

### 3. `GET /lessons/:id/transcript` (админ)

`findAll()` ба `findOne()`-оос `content.transcript`-ыг **хасна**. Шалтгаан
хоёр: сурагчийн апп руу 20KB бичвэр явуулах утга алга; транскрипт бол
зохиогчийн материал.

Админ засах цонх нээгдэхэд транскриптийг **энэ endpoint-оос тусад нь** татна.

### 3a. Транскрипт бол СЕРВЕРИЙН эзэмшилтэй талбар

⚠️ `admin/src/pages/lessons/LessonsPage.tsx:112` дээр `content`-ийн merge нь
**клиент талд** хийгддэг (`{ ...(editing?.content ?? {}) }`), `editing` нь
жагсаалтын хариунаас ирдэг. Тиймээс `findAll()`-оос транскриптийг хасвал
админ хичээлээ дараагийн удаа хадгалахад тэр merge нь **транскриптийг
устгана**.

Тиймээс:

- `PATCH /lessons/:id` нь `content.transcript`-ыг **үргэлж хэвээр үлдээнэ**
  (payload-ын `content` дотор байсан ч, байхгүй ч хамаагүй). Транскриптийг
  энэ замаар бичих боломжгүй.
- Засварт тусдаа **`PATCH /lessons/:id/transcript`** (body: `{ text }`).

Ингэснээр "клиентийн merge серверийн датаг дардаг" ангиллын алдаа бүтцийн
хувьд боломжгүй болно. Гурван жижиг route (`transcribe` · `GET transcript` ·
`PATCH transcript`) нь тус бүр өчүүхэн, харин хариуцлагын хил тодорхой.

### 4. Зардлын бүртгэл

`ai_usages` мөр: `type: STT`, `voiceSeconds`, `userId` = **админ**,
`metadata: { purpose: 'lesson_transcript', lessonId }`.

Сурагчийн `plans.sttMinutesLimit` рүү **хүрэхгүй** — тэр хязгаарууд buddy-ийн
дуудлагын цэг дээр тусад нь шалгагддаг тул мөр бичих нь өөрөө хязгаар иддэггүй.

## Prompt (`backend/src/quizzes/ai-generate.ts`)

`GenerateOptions`-д **`lessonSource?: string`** нэмнэ. `contextNote` дотор
6000 тэмдэгт шахахгүй — тусдаа, тодорхой блок болгоно:

```
ХИЧЭЭЛИЙН АГУУЛГА (видеоны бичвэр):
"""..."""
```

`kindContext(kind === 'lesson')`-д нэмэх заавар:

> Энэ бичвэр нь монгол багшийн тайлбар бөгөөд дунд нь англи жишээ орсон,
> автоматаар хөрвүүлсэн тул алдаатай байж болно. Асуултыг зөвхөн энд заасан
> материал дээр үндэслэ. Бичвэрийн монгол хэсгийг сэдэв тодорхойлоход ашигла,
> асуултыг англиар бич.

**Таслах хязгаар: 12,000 тэмдэгт.** Зардлыг урьдчилан таамаглахуйц байлгах,
`runGeminiText`-ийн `MAX_TOKENS` хамгаалалтад мөргөхгүй байх үүднээс.

## Admin UI

- **`LessonsPage`** — видео талбарын доор «Видеоноос бичвэр гаргах» товч +
  задардаг textarea (тэмдэгтийн тоолуур, засвар хадгалагдана). Алдааг
  `ErrorBox` + `lib/errors.ts` → `friendlyError()`-оор.
- **`LessonTests`** — `AiBulkGenerator`-ийн `target`-д `lessonSource` нэмнэ.
  Хичээлд видео байгаа мөртлөө транскрипт байхгүй бол цонхон дотроос шууд
  «Видеоноос бичвэр гаргах» санал болгоно — админд нэг урсгал шиг мэдрэгдэнэ.

Одоо байгаа `Publish.tsx` дүрэм хэвээр: нийтлэх төлөвийн UI хуудсанд бичихгүй,
шинэ `isPublished` checkbox нэмэхгүй.

## Тест

`ai-generate.spec.ts`-ийн загвараар, цэвэр функц дээр (сүлжээ/DB хөндөхгүй):

1. `lessonSource` prompt-д зөв блок болж орж байна.
2. 12,000 тэмдэгтийн таслалт ажиллана.
3. `content` merge нь `videoUrl`/`imageUrl`-ыг хадгална.
4. Жагсаалтын хариунаас `content.transcript` хасагдана.
5. Видеогүй хичээл дээр `400` буцна.

## Хамрах хүрээнд ОРООГҮЙ (YAGNI)

Upload дээр автомат хөрвүүлэлт · субтитр үүсгэх · транскриптээс үг автоматаар
гаргах · Gemini-ийн видео горим · webhook (async) STT. Эхлээд ганц гинжийг
ажиллуулна.

## Deploy-ийн тэмдэглэл

- Шинэ хүснэгт/багана **алга** → migration шаардлагагүй (`content` нь одоо ч
  jsonb).
- `ELEVENLABS_API_KEY` prod дээр аль хэдийн тохируулагдсан (buddy voice + үгийн
  audio түүгээр явдаг). Шинэ env хувьсагч нэмэхгүй.
- Админы өөрчлөлт Vercel дээр шууд, backend Railway дээр шууд — аппын шинэ
  bundle **шаардахгүй** (сурагчийн тал огт хөндөгдөхгүй).
