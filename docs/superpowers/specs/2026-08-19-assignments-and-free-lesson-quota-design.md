# Багшийн даалгавар + 3 үнэгүй хичээлийн квот — дизайн

**Огноо:** 2026-08-19 · **Санаачлагч:** Choi · **Салбар:** `feat/choi-assignments-and-free-lessons`

> Энэ баримт нь 3 хөгжүүлэгчийн эзэмшлийн хилээр огтолж гарах тул **шийдвэрүүдийг
> нэг дор бичив**. Код бичихээсээ өмнө уншина уу.

---

## 1. Юуны төлөө

Хоёр тусдаа зорилго нэг урсгалд нийлж байна:

1. **Багш → сурагч руу даалгавар очих нь бодитоор мэдрэгддэг болох.** Одоо
   даалгавар өгөхөд сурагч руу **юу ч очдоггүй** — сурагч өөрөө `/assignments`
   рүү орж шалгаж байж мэднэ. «Анги тарлаа, гэртээ харилаа, багшаас даалгавар
   ирлээ» гэсэн мэдрэмж энэ feature-ийн цөм.
2. **Үнэгүй хэрэглэгчийг төлбөрт шилжүүлэх.** Сурагч өөрөө сонирхлоороо үзэх
   хичээл **3-аар хязгаарлагдана**; түүнээс хойш багц авна.

Хоёр нь мөргөлдөх боломжтой тул доорх **§3-ын дүрэм** заавал мөрдөгдөнө.

## 3. Шийдвэрүүд (баталгаажсан)

### 3.1 Гол дүрэм — багшийн даалгавар квотоос ЧӨЛӨӨТЭЙ

> **Багшийн өгсөн даалгаврыг сурагч ҮРГЭЛЖ, ҮНЭГҮЙ хийнэ.** 3 эрхийн квот
> түүнд огт хамаарахгүй.

Учир нь: сурагч гэрийн даалгавраа хийх гэтэл paywall гарвал багш маргааш
өөр апп руу шилжинэ. 1 багш ≈ 30 сурагч — манай хамгийн хямд суваг. Мөн
сургууль төлбөрөө төлчихөөд сурагч дахин төлөх нь утгагүй.

Квот нь **зөвхөн сурагч өөрөө сонирхлоороо нээж буй** хичээлд үйлчилнэ.

### 3.2 Квотын нарийвчлал

| Асуулт | Шийдвэр |
| --- | --- |
| Хэдэн эрх? | **Үүрд 3 хичээл** (өдөр/сараар сэргэхгүй) |
| Юу эрх иддэг? | **Зөвхөн хичээл** (`/lesson/:id`). Дасгал · Сорил · Унших · Хэлц · Толь · SRS давталт · IELTS бүгд **үнэгүй хэвээр** |
| Хэзээ иддэг? | Сурагч **«Эхлэх» дарж баталгаажуулахад**. Дэлгэц нээх нь үнэгүй |
| Дахин нээвэл? | **Эрх идэхгүй** — нэг удаа нээсэн хичээл үүрд тухайн хүнийх |
| Эрх дуусвал? | Хичээл нээгдэнэ, **гарчиг/тайлбар/зураг харагдана**, агуулга бүдэгтэж «Багц авах» |
| Багц авбал? | **Бүх хичээл нээгдэнэ** (нэг нэгээр нь худалдаж авахгүй) |
| Sparks-аар нэгээр нь? | **Үгүй.** Хичээл нээх цорын ганц зам = багц |
| Хуучин хэрэглэгч? | **Grandfather** — өмнө дуусгасан бүх хичээл үүрд нээлттэй, дээр нь 3 шинэ эрх |

### 3.3 Оноо

**«Оноо» = дүн хувь (`scorePct`, 0–100).** Даалгавар XP олгохгүй хэвээр
(`API.md` §6a өөрчлөгдөхгүй) — эс бөгөөс багш нэг сорилыг дахин дахин оноож
XP тариалах зам нээгдэнэ. Шинэ зүйл нь зөвхөн UI: сурагч даалгавраа **хийхээс
өмнө** «энэ хэдэн оноотой вэ» гэдгээ хардаг болно.

## 4. Хэрэгжүүлэлт

### 4.1 Хичээлийн хандалт — `lesson_unlocks`-ыг дахин ашиглана

Шинэ хүснэгт **үүсгэхгүй**. `lesson_unlocks` бол аль хэдийн «энэ хичээл
надад үүрд нээлттэй» гэсэн мөр — зөвхөн *яагаад* нээгдснийг нэмнэ:

```
lesson_unlocks
  + source: 'sparks' | 'free' | 'assignment' | 'legacy'
  ~ sparks_spent: NOT NULL → nullable (sparks-аас бусад эх сурвалжид утгагүй)
```

**Хандалтын дүрэм** (сервер тал, `LessonAccessService`):

1. Идэвхтэй багцтай (`planId != null && planExpiresAt > now`) → **бүх хичээл**
2. `lesson_unlocks` мөр байна → **нээлттэй**
3. Тухайн хичээл багшаас **оноогдсон** → **нээлттэй**, эрх идэхгүй
   (+ `source='assignment'` мөр үүсгэнэ, ингэснээр даалгавар устсан ч хэвээр)
4. Үгүй бол → **түгжээтэй**, `freeRemaining = 3 − count(source='free')`

**⚠️ Дүрэм:** түгжээг **зөвхөн сервер тал** шийднэ. Апп-аас ирсэн туг
хэзээ ч итгэмжлэгдэхгүй — эс бөгөөс энэ бол үнэгүй хичээлийн унтраалга.

### 4.2 Мэдэгдэл

**🐛 Эхлээд нэг алдаа зассан:** `mobile/src/api/notifications.ts` нь
`GET /notifications/me` дуудаж байсан ч backend дээр **тэр зам байхгүй** —
`notifications.controller.ts`-д зөвхөн `GET /` (admin) бий. Апп доторх
мэдэгдлийн төв 404 идэж, хоосон харагдаж байсан.

`notifications` хүснэгтэд:

```
  + user_id: uuid nullable   -- NULL = broadcast (хуучин зан төлөв хэвээр)
  + data: jsonb nullable     -- deep link, ж: { type: 'assignment', url: '/assignments' }
```

`GET /notifications/me` → `user_id = me` **ЭСВЭЛ** (`user_id IS NULL` **AND**
(`target_role IS NULL` **OR** `target_role = my role`)), шинэ нь эхэнд.

`POST /assignments` дотор: зорилтот сурагч бүрд мэдэгдлийн мөр + push.
Push нь **best-effort** — унасан ч даалгавар үүсгэх нь бүтэлгүйтэхгүй.

## 6. Deploy дараалал

1. **Backend түрүүлж** гарна (migration + шинэ endpoint).
2. Дараа нь **аппын шинэ bundle** (OTA).

Урвуу дараалал эвдэрнэ: шинэ апп `/lessons/:id/access` рүү 404 авна.
Backend түрүүлбэл ямар ч эвдрэл алга — хуучин апп шинэ талбаруудыг зүгээр л
үл тоомсорлоно.

**⚠️ Railway дээр `DB_MIGRATIONS_RUN=true` эсэхийг шалгаж байж deploy хий**
(legacy backfill ажиллахгүй бол хуучин хэрэглэгчид түгжигдэнэ).

## 7. QPay хүлээж буй хэсэг

`PAYMENTS_ENABLED` **хаалттай** хэвээр (`CLAUDE.md` — launch blocker). Тиймээс
paywall-ийн **UI бүхэлдээ бэлдэгдэнэ**, харин «Багц авах» товч одоогоор
`/plan` руу л аваачна. QPay бэлэн болмогц тэр нэг цэгийг холбоно.

**⚠️ QPay бэлэн болтол `FREE_LESSON_QUOTA_ENABLED=false` байна** — эс бөгөөс
сурагчдыг хааж байгаад мөнгө авах боломжгүй болно. Хаалттай үед бүх хичээл
нээлттэй (одоогийн зан төлөв яг хэвээр).
