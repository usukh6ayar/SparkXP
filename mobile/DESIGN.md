# Theming — Light / Dark (ЭНЭ ХЭСГИЙГ ЗААВАЛ УНШ)

> **Гол дүрэм:** Settings дэх appearance toggle-ийг (☀️ Light / 🌙 Dark) дарахад
> **дэлгэц дээрх БҮХ дизайны элемент** (background, card, текст, border, track,
> divider, icon tint …) дагаад солигдох ёстой. Ганц ч hardcode хийсэн өнгө
> үлдээж болохгүй — үлдвэл тэр элемент горим солиход "гацна".

## Яаж ажилладаг (архитектур)

Өнгөний **ганц эх сурвалж (single source of truth)** нь `mobile/src/theme/theme.ts`.
Тэнд хоёр palette тодорхойлогдсон:

- **`appThemes`** = `{ dark, light }` — апп даяарх ерөнхий palette (`AppColors`).
  Ихэнх дэлгэц / компонент үүнийг ашиглана.
- **`premiumThemes`** = `{ dark, light }` — Profile / Settings маягийн "premium
  surface" дэлгэцүүдийн palette (`PremiumPalette`).

Идэвхтэй горимыг хадгалж, солих логик нь `mobile/src/settings/SettingsContext.tsx`.
Сонголт **AsyncStorage**-д хадгалагдаж, апп дахин нээхэд сэргэдэг. Default = **dark**.

## Дэлгэц / компонент дотор өнгийг ЯАЖ авах вэ

Screen эсвэл component дотор өнгийг **hook-оор** ав — импортоор биш:

```tsx
import { useColors } from '../src/settings/SettingsContext'; // ерөнхий palette
// эсвэл
import { useTheme } from '../src/settings/SettingsContext';  // premium palette

function Screen() {
  const c = useColors();            // идэвхтэй (light/dark) palette
  const styles = makeStyles(c);     // style-г palette-аас БҮТЭЭ
  return <View style={styles.card} />;
}
```

- ✅ `const c = useColors()` → `c.background`, `c.text`, `c.surface`, `c.border` …
  Toggle солиход энэ компонент дахин render хийгдэж, шинэ өнгө автоматаар орно.
- ✅ StyleSheet-ээ palette-аас бүтээ (`makeStyles(c)`) эсвэл inline `style={{ color: c.text }}`.
- ❌ `import { colors } from '.../theme'` дараа `colors.background` гэж
  **шууд ашиглаж болохгүй** — энэ бол dark горимд царцсан статик утга,
  toggle-ийг дагахгүй.
- ❌ `'#191040'`, `'#FFFFFF'` гэх мэт hex-ийг дэлгэцэнд шууд бичиж болохгүй.

> **Legacy тэмдэглэл:** `theme.ts` доторх экспортлосон `colors` объект нь
> `appThemes.dark`-тай тэнцүү бөгөөд зөвхөн **шилжүүлж амжаагүй хуучин дэлгэцүүд**
> ажилласаар байхын тулд үлдээсэн. Шинэ болон засварласан код **заавал**
> `useColors()` / `useTheme()` ашиглана. `static colors` импорт = migration өр.

## Одоогийн migration статус (2026-07)

Theme дэд бүтэц бэлэн, гэхдээ дэлгэцүүд бүрэн шилжиж амжаагүй:

- ✅ `useColors()` / `useTheme()` reactive-аар ашигладаг: ~16 файл (солигддог).
- ⚠️ static `colors`-г шууд импортолсон: ~56 файл (dark-д царцсан, солигдохгүй).

**Definition of done (light/dark бүрэн ажиллаж дуусах):** аппын аль ч дэлгэц дээр
static `colors` импорт үлдээгүй, бүх screen `useColors()`/`useTheme()`-аар өнгө
авдаг болсон үед л "элемент бүр дагаж солигдоно" гэсэн шаардлага биелнэ. Энэ
migration нь `theme.ts` + `src/components/*` (shared файлууд) хамардаг тул
багтай зохицуулж, жижиг PR-аар хийнэ (`TEAM_WORKFLOW.md`).

## Семантик токен зарчим (өнгийг УТГА-аар нь нэрлэ)

Toggle-г дагаж зөв солигдохын тулд токенийг **утгаар** (intent) нь ашигла,
шаталсан hex-ээр биш. Ижил токен light/dark хоёулаа "зөв" харагдана:

| Токен (`useColors()`)       | Утга / хаана                                  |
| --------------------------- | --------------------------------------------- |
| `background`                | Дэлгэцний суурь дэвсгэр                        |
| `backgroundGradient`        | Дэвсгэрийн градиент (2 өнгө)                   |
| `surface`                   | Карт / өргөгдсөн гадаргуу                      |
| `surfaceAlt`                | Хоёрдогч гадаргуу — input, chip, track        |
| `text`                      | Үндсэн текст (эрчимтэй)                        |
| `textSecondary`             | Хоёрдогч текст                                 |
| `textMuted`                 | Caption / hint / идэвхгүй                      |
| `border` / `borderStrong`   | Зөөлөн / хүчтэй хүрээ                          |
| `primary` / `primaryGradient` | Brand үйлдэл, CTA, XP, active state          |
| `success` `warning` `danger`| Семантик төлөв                                |
| `xp` `sparks` `streak`      | Gamification accent                            |

**Brand / gamification / semantic өнгө** (`primary`, `success`, `xp`, `streak`,
`sparks`, `danger`…) light/dark хоёулаа **ижил** байна — зөвхөн гадаргуу, текст,
хүрээ ялгаатай. Тиймээс горим солиход брэнд царай хадгалагдана.

# Shadows / Elevation

Elevation нь **горимоос хамаарна**:

- **Light** горимд: сонгодог зөөлөн хар сүүдэр — `0 8 24 rgba(0,0,0,0.06)`.
- **Dark** горимд: хар сүүдэр харагдахгүй тул картыг **зөөлөн ягаан гэрлээр**
  (`#9D7BFF` glow) "хөвүүлнэ". Floating элемент (FAB / төв таб) арай хүчтэй
  primary glow-той.

Хатуу хар хүрээ (harsh border) хэзээ ч бүү хэрэглэ.

## Bottom Navigation

**Soft-wave tab bar (2026-08-03 — шил/glass болив).** Код:
`src/components/CustomTabBar.tsx` + `src/components/tabbar/` (`WaveCard` = дүрс ·
`TabItem` = хавтгай таб · `BuddyTab` = төв CTA · `geometry.ts` = бүх тоо).

- Карт: хотгор дээрээ **64px**, хажуугийн товгор дээрээ 75.5px (+ safe area).
- **Safe area-гаас 8px эргүүлэн авдаг** (`cardBottom = max(inset − 8, 12)`).
  Систем inset нь бүтэн өндөртэй элементэд зориулагдсан, манай шошго жижиг тул:
  34pt inset дээр шошго дэлгэцийн ирмэгээс **30px** дээр сууна — home indicator
  доод ~21px-ийг эзэлдэг тул цэвэр. Доод хязгаар 12px нь gesture-nav утсанд.
- **Булангийн радиус 48** (спекийн 32–36-аас зориуд том). Долгион нь булан
  эхлэх яг тэр цэгтээ **хамгийн өндөр** байдаг тул нарийн булан нь тэр оргилоос
  хад мэт унаж, хоёр үзүүр «дээшээ гарсан арал» шиг харагддаг. Өргөн булан нь
  товгорыг дэлгэцийн ирмэг рүү **эргэлдүүлэн буулгана**. Сүүдэр татдаг тэгш
  өнцөгт ижил радиус хэрэглэдэг — тиймээс тэр нь долгионоос тогтмол `WAVE_H + 3`
  гүнд сууж, хэзээ ч цухуйхгүй.
- **Дээд ирмэг = КОСИНУСЫН ЭГНЭЭ, макетаас шууд хэмжсэн:**

  ```
  depth(u) = Σ Aₖ·(1 − cos 2πk·u)      u = 0…1 (буланаас булан)
  WAVE_COS = [4.17, 3.4, −0.72]
  ```

  Эдгээр тоо нь **таашаал биш** — макетын ирмэгийг пиксельээр уншиж, косинусын
  эгнээгээр **хамгийн бага квадратаар тохируулсан** үр дүн (алдаа ≈2dp, энэ нь
  макетын өөрийнх нь зүүн/баруун тэгш бус байдал — тэгш хэмтэй муруй дундажийг
  нь л барина). Юу гэсэн үг вэ:

  | Хаана | Өндөр |
  | --- | --- |
  | **хажуугийн товгор** (гадна табуудын дээр) — ХАМГИЙН ӨНДӨР | 75.5 |
  | дунд нь дахин өргөгдөнө, гэхдээ **хагас орчим** | 68.6 |
  | хотгор (гуравны нэгд, табуудын хооронд) | 64 = `BAR_H` |

  ⚠️ Тохируулгын түүхий тоо нь `[6.26, 6.07, −1.97, 0.36]` байсан. Ажилд ороод
  байгаа нь түүнийг **66% болгож жижигрүүлээд, гармоник бүрийг улам дарсан**
  (×0.85, ×0.55) хувилбар. Дүрс нь ижил, гэхдээ **намхан бөгөөд зөөлөн** —
  түүхий тохируулга утсан дээр «шахагдсан» долгион шиг харагдсан, учир нь
  өндөр гармоникууд гэдэг чинь яг тэр богино, огцом ганхалт юм.

  ⚠️ **Дунд нь хамгийн өндөр БИШ.** Макет дээр үнэг оргил дээр сууж байгаа юм
  биш, даруухан өргөлтөөс **21dp дээгүүр хөвж** байна. Дундыг хамгийн өндөр
  болгосон өмнөх оролдлогууд яг үүнээс болж «огт өөр» харагдсан.
- Косинусын эгнээ бол зүгээр нэг таарсан муруй биш, **зөв хэлбэрийн томьёо**:
  `cos(2πk·u)` бүр дунджаараа тэгш хэмтэй бөгөөд хоёр үзүүртээ хавтгай тул
  долгион **тэгш хэм ба булангийн хэвтээ шүргэгчийг үнэгүй** авна. Бүх цэгтээ
  гөлгөр — залгах зангилаагүй тул хугарах газаргүй. (2026-08-03-д оргилуудыг
  гараар жагсааж үзсэн нь утасны хэмжээнд «овон товон» харагдсан.)
- **Дүрсний зай (энэ л бариултай тоо):** дүрсний орой `LABEL_BOTTOM + шошго 14 +
  TAB_GAP + TAB_ICON` = **55**, туузны ёроол = ирмэг − `BAND`. Амарч байхад:
  гадна **14.3px** · дотор **4.4px**; таб дарах түлхэлт болон морфинг хамгийн
  муугаараа давхацсан агшинд дотор нь **2.5px**. Дүрсний **булан** дээр (долгион
  налуу тул) хамгийн нам нь 3.3px — 3D зураг дотроо ~2px тунгалаг зайтай, мөн
  зургийн булан нь хамгийн хоосон хэсэг тул бодит зураас хүрэхгүй.

### Долгион амьсгална (2026-08-03)

Зам нь **frame бүрт дахин зурагдана** — `reanimated`-ийн worklet дотор
(`useAnimatedProps`), **UI thread** дээр. JS thread огт оролцохгүй тул дэлгэц
ачаалж/гүйлгэж байхад долгион чичрэхгүй.

| Хувьсагч | Юу хөдлөх | Хэмжээ |
| --- | --- | --- |
| `MORPH` | гармоник бүр **өөрийн хурдаараа** амьсгална | 16% · 22% · 40% |
| `SPLASH` | таб дарахад долгион бүхэлдээ түлхэгдэж, буцаж тогтоно | 16% |
| `ROLL` | долгион **хажуу тийш найгана** (нэг мөр өргөгдөхөд нөгөө нь суух) | 1.2px |

- **`ROLL` — тэгш бус хөдөлгөөн.** Бусад бүх гишүүн тэгш хэмтэй бөгөөд тэгш хэмтэй
  хөдөлгөөн нь «машин амьсгалж байгаа» шиг уншигддаг. `ROLL` нь **синус** гишүүн
  (тэгш бус) тул нэг мөр өргөгдөхөд нөгөө нь суух — ус яг ингэж найгадаг. Хоёр
  булан дээрээ тэглэгддэг (sin 0 = sin 2π = 0) тул үзүүр хөдлөхгүй; тэнд налуу нь
  ~0.03 px/px, булангийн нумтай харьцуулахад мэдэгдэхгүй.
- **ХОЁР хотгор хоёулаа ХАДАГДСАН (`DIP_U`).** Гүнийг тухайн агшны **илүү гүн**
  хотгорын гүнд хуваан нормчилно — тиймээс аль ч хотгор `BAR_H`-аас доош
  унахгүй, долгион хэрхэн ч найгасан.
  Энэ л зүйл хөдөлгөөнийг харагдахуйц болгож байгаа юм: дүрснүүд өнгөт туузнаас
  хотгор дээрээ ердөө ~3px зайтай тул нормчлолгүй бол амьсгалалт болгон тэр зайг
  иддэг байсан (тиймээс хөдөлгөөнийг бараг үл мэдэг болгож багасгах хэрэгтэй
  болдог). Хадсаны дараа **хөдөлгөөнийг 2 дахин томруулав**.
- ⚠️ **ЮУ Ч ЗӨӨГДӨХГҮЙ.** Эхний оролдлогод долгионыг хажуу тийш гулсуулж
  (`SWAY`) байсан нь «барыг чирч байгаа» мэт харагдсан тул хассан. Одоо зөвхөн
  **коэффициентүүд** өөрчлөгдөнө: `cos(2πk·u)` бүр хоёр үзүүртээ хадагдсан тул
  ямар ч морфинг долгионыг булангаас нь салгаж, ирмэг ил гаргаж чадахгүй.
- Давтамжууд нь **нэг цагийн 1× · 2× · 3×** тул мөчлөг бүр бүтэн тоогоор дуусч,
  давталтын заагт **үсрэлт гарахгүй**. Бүгд цэвэр синус тул **phase 0 =
  хөдөлгөөнгүй хэлбэр** → Reduce Motion яг тэнд зогсоно.
- 🐞 **Зассан алдаа (2026-08-03):** таб сонгоход карт `translateX`-ээр 6px хүртэл
  **хажуу тийш гулсдаг** байв (`drift`). Захын таб (Home) дээр дарахад бүхэл карт
  зүүн тийш явж, **баруун захад (Profile-ийн хажууд) зай** ангайдаг байсан. Одоо
  хариу нь гулсалт биш **түлхэлт** (`SPLASH`) — ил гарах ирмэг гэж байхгүй.
- Сүүдэр татдаг тэгш өнцөгтийн дээд ирмэг нь хотгорын гүнээс **3px доор** суудаг:
  хотгор амьсгалж гүнзгийрэхэд тэгш ирмэг нь муруйн дээгүүр цагаан зурвас болж
  цухуйхаас сэргийлнэ.
- Гурван зам (градиент · surface · bloom) **нэг цаг** уншина → тууз ирмэгээсээ
  хэзээ ч салахгүй.
- Муруйг **түүвэрлэж** (12 цэг) Hermite сплайнаар холбоно; налууг нь тоон
  аргаар (төв ялгавар) хэмждэг тул анимаци муруйг хэрхэн ч нугалсан шүргэгчид
  нь тохирсон хэвээр байна.
- **Цул гадаргуу — glassmorphism БИШ.** `BlurView` хассан; карт нь `colors.surface`
  (light цагаан · dark өргөгдсөн индиго). Blur нь доогуур гүйж буй контентын
  өнгийг татдаг тул дүрснүүдийн доорх гадаргуу байнга өөрчлөгдөж, тайван
  сэтгэгдлийг эвддэг.
- **Туяа = 8px өнгөт ТУУЗ (`BAND`, 2026-08-03, Choi).** Макетаас пиксельээр
  хэмжсэн: тууз нь 16–18px зузаан, картын их бие 127px → макет 2× масштабтай тул
  тууз ≈ **8dp**. Нарийн зураас биш! Макет дээр туузны **дээд ирмэг нь картын
  ирмэг** (дэлгэцтэй хатуу зааг), өнгө нь **карт руугаа дотогшоо** сууна — нимгэн
  stroke яагаад ч адилхан харагдахгүйн шалтгаан нь энэ.
  - Өнгө (мөн макетаас): `#8D5FFF → #A98CFF → #DE7CF5 → #A9AEFC → #6891FB`.
    Пастель — 55–65% гэрэлтэйгээр. Брэндийн бүтэн ханалт руу татвал highlighter
    маркер шиг болно.
  - **Яаж зурсан бэ (заль):** ижил замыг хоёр удаа дүүргэнэ — эхлээд **градиентаар**,
    дараа нь **`surface` өнгөөр `dy = BAND`-аар доошлуулж**. Үлдсэн зөрүү нь яг
    туузыг үлдээнэ — clip path, mask, filter огт хэрэггүй, тууз нь давалгааны
    эргэлт бүрийг үнэгүй дагана (`wavePath(w, h, dy)`).
  - Гадна талд нь **бараг үл мэдэг bloom** (7px @10% · 3px @14%) — макет дээр
    байхгүй ч бараан дэлгэц дээр карт хайчаар тайрсан мэт харагдахаас сэргийлнэ.
    `GLOW_PAD` (10px) нь SVG-ийн `viewBox`-ыг дээш өргөж, bloom тасрахгүй.
- Сүүдэр: ганцхан зөөлөн `blur 22 · 9%`, өнгө нь **саарал/бараан** (theme-ийн ягаан
  `elevation.*` БИШ). Офсет нь **`y −10`** — сүүдэр татдаг тэгш өнцөгтийн дээд ирмэг
  нь давалгааны шугамаас нэлээд **доор** суудаг (эс бөгөөс хотгоруудад тэгш ирмэг
  нь цухуйна), тиймээс бага офсеттэй бол сүүдэр бүхэлдээ картан доор нуугдана.
- Дүрс: **брэндийн 3D PNG** (`appIcons` → `<AppIcon size={TAB_ICON}>`, **34px**;
  3D зураг нь дотроо тунгалаг зайтай тул вектор глифээс жижиг уншигддаг — хуучин
  шошгогүй бар 40px зурдаг байсан) —
  Нүүр `home` · Хичээл `reading` · Сорил `trophy` · Профайл `profile`.
  Шошго: `typography.tabLabel` (11px).
- Идэвхтэй таб: дүрс **бүрэн тод** (идэвхгүй нь `opacity 0.6`) + 1.06 томорно,
  шошго ягаан. 3D зургийг **өнгөөр будаж болдоггүй** тул идэвхтэйг зөвхөн
  тунгалагшилт+хэмжээ илэрхийлнэ.
- ⚠️ **Дүрсний доор юу ч нэмж БОЛОХГҮЙ** (зураас · pill · капсул · дэвсгэр) бөгөөд
  **дээш нь өргөж ч болохгүй**. Давалгаа дотор табуудын дээгүүр хамгийн нам байдаг
  тул дүрсний доорх px бүр дүрсийг өнгөт тууз руу түлхэнэ. #199-ийн `LIFT = 8` +
  18×3 зураас хоёулаа яг үүнийг хийж, дүрс давалгааг цоолж гарч байв. Идэвхтэйг
  зөвхөн **гэрлээр** (тунгалагшилт + өнгө) хэл — макет ч мөн адил.
- Табын мөр `bottom: insets.bottom` дээр суух тул safe area-г идэхгүй (өмнө нь
  home indicator руу шахагддаг байсан). Мөрний `alignItems: 'stretch'` — таб бүр
  картын өндрийг дүүргэж, өөрийн баганаа **доод талд нь** зэрэгцүүлнэ
  (`paddingBottom: LABEL_BOTTOM`); ингэснээр илүү зай нь **дүрсний дээр**, яг
  давалгаанд хэрэгтэй газраа очно.
- Center: Spark Fox — **60px** (54 зураг + 3 цагираг), градиент
  цагираг, **шошготой** (`AI Buddy`, үргэлж ягаан — идэвхгүй байсан ч hero хэвээр).
  Дундах өргөлтөөс **~24px дээгүүр хөвнө**.
- ⚠️ **`BUDDY_OVERHANG` (29px) — картаас дээш цухуйх хэмжээ.** Бар нь дэлгэцүүдээс
  зөвхөн **картаа** (`tabBarHeight()`) хоосон үлдээхийг шаарддаг тул үнэг энэ
  хэмжээгээр доорх контент дээгүүр хөвнө. Дэлгэцийн **ёроолд наасан товч** байгаа
  бол энэ тоог заавал нэм — эс бөгөөс үнэг товчин дээр буучихна. (`BuddySelector`
  дээр яг ийм алдаа гарсан: Apply товчны доод ирмэг дээр үнэг наалдсан → `wrap`-ийн
  `paddingBottom`-д нэмэв.) Амарч байхдаа **аажим амьсгална** (≈4.4с мөчлөг, 3.5%);
  Reduce Motion үед бүрэн унтарна.
- **Таван шошго нэг шугаман дээр.** Buddy баганыг зургаар нь биш **шошгоороо**
  байрлуулна. Таб ба buddy хоёр **нэг тоог** уншина — `LABEL_BOTTOM` (6) — тул
  таван шошго зөрөх боломжгүй.

### ⚠️ Хоёр өндөр — хольж болохгүй (2026-08-03 засвар)

`geometry.ts` дотор **хоёр өөр** өндөр байна:

| | Юу вэ | Хэмжээ |
|---|---|---|
| `TOTAL_H` | Таб барын **өөрийн view** — карт + давалгаа + buddy хөвөх тунгалаг зурвас | 104 + safe area |
| `tabBarHeight(inset)` | Дэлгэцүүд **хоосон үлдээх ёстой** зай — зөвхөн цул карт | 64 + safe area |

- `CustomTabBar`-ийн үндсэн view нь **`position: absolute`** (overlay) — React
  Navigation таб барыг дэлгэцүүдтэй нэг flex багананд тавьдаг тул урсгал дотор
  байвал тунгалаг зурвас нь **дэлгэц болгоноос ~40px иддэг** (2026-08-03-аас өмнө
  ингэж байгаад бүх дэлгэцийн бүтэц дээшээ шахагдаж эвдэрсэн).
- Оронд нь `app/(tabs)/_layout.tsx` нь `sceneStyle.paddingBottom =
  tabBarHeight(insets.bottom)` өгнө. **Зөвхөн цул карт** зай авах эрхтэй.
- View нь картаас өндөр хэвээр байх ёстой: **Android дээр эцэг view-ээсээ гадуур
  зурагдсан хэсэг дардаггүй** тул buddy тэр зурвас дотроо багтсан байх ёстой
  (`box-none` тул тунгалаг хэсэг дээрх даралт доорх дэлгэц рүү дамжина).
